# 背题软件 · 极空间 Z2S 部署说明

## 原理
把前端构建产物 `dist/`（纯静态文件）用极空间 Docker 里的 Nginx 托管，手机/电脑通过浏览器访问即可。

- 你的题库、进度、错题**全程存在你手机/电脑浏览器本地（IndexedDB）**，不会上传到极空间，隐私不变。
- 首次联网打开后，PWA 会把应用缓存进手机，**之后离线也能背**（数据一直在本地）。

---

## 一、在电脑上确认静态产物（已帮你生成）
项目里 `dist/` 就是构建产物（已是最新，含全部功能）。若你之后改过代码，先在项目目录跑：
```
npm run build
```

## 二、把 dist 传到极空间
1. 极空间网页/客户端 → 文件 → 新建共享文件夹，例如 `beiti`。
2. 把电脑上 `dist/` 里的**全部内容**上传进去（`index.html`、`assets/`、`sw.js`、`manifest.webmanifest` 等）。
   - 方式任选：极空间网页直接上传；或用 SMB / WebDAV 拷贝；或先打成 zip 上传再解压。
3. 记下这个目录在极空间的完整路径，例如 `/共享/beiti`（下面挂载要用）。

## 三、极空间 Docker 创建 Nginx 容器（图形界面，不用敲命令）
1. 极空间 → 应用中心 / Docker → 镜像仓库 → 搜 `nginx` → 拉取**官方** `nginx:alpine`（多架构镜像，Z2S 的 ARM 会自动适配）。
2. 创建容器，配置：
   - **端口映射**：本地（宿主机）`8082` → 容器 `80`。
   - **目录挂载**（只读 ro 建议）：
     - 极空间上的 `beiti` 目录 → 容器 `/usr/share/nginx/html`
     - 本项目 `deploy/nginx/nginx.conf` → 容器 `/etc/nginx/conf.d/default.conf`
   - **环境变量**（可选）：`TZ = Asia/Shanghai`。
   - 勾选「开机自启」。
3. 启动容器。浏览器访问 `http://极空间局域网IP:8082`，看到背题软件首页即成功（内网可用）。

> 嫌图形界面麻烦，也可以用 `deploy/nginx/docker-compose.yml`（把 volumes 里的路径改成你极空间的真实路径），在支持 compose 的极空间 Docker 里导入。

## 四、让手机在单位 / 流量下也能访问
两种任选其一：

**方式 A（推荐，无需公网 IP、无需域名）—— 极空间自带远程访问**
- 极空间 App / 网页 → 远程访问 → 添加「自定义服务」，指向 `http://极空间局域网IP:8082`（或 `127.0.0.1:8082`）。
- 在外网用极空间给的远程地址打开即可。
- ⚠️ 若外网打不开容器端口：进 **系统设置 → 安全中心 → 高级设置**，勾选「允许第三方 Docker 应用通过 HTTP 访问」，保存后重启 Docker 服务再试。

**方式 B（有自己的域名 / 公网 IP）—— 反向代理或端口转发**
- 极空间 → 系统设置 → 远程访问 → 反向代理：源域名 → `127.0.0.1:8082`。
- 或路由器做 DDNS + 端口转发（8082），直接 `域名:8082` 访问。

## 五、手机使用
- 内网：浏览器开 `http://极空间局域网IP:8082`。
- 外网：开远程访问地址 / 域名。
- 首次打开后，「添加到主屏幕」装成 App；之后离线也能开（数据本地）。

## 六、以后更新代码
改完代码 → 电脑 `npm run build` → 把新 `dist/` 覆盖上传到极空间 `beiti` 目录 → Nginx 自动生效（页面强刷一下）。

## 七、注意事项
- Z2S 性能有限，但只托管静态文件绰绰有余。
- 极空间若关机 / 休眠，外网访问会中断；建议设置「不自动休眠」或固定时段开机。
- 数据不上极空间，但建议定期用 App 内「备份」导出 JSON 存到极空间文件，给题库 + 进度多一份保险。
